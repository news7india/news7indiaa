# News 7 India - Flutter Android News App

Official Android mobile application for https://www.news7india.com/ built with Flutter & Dart.

## Key Features
1. **Reader View**: Latest news feed powered by WordPress REST API with categories, instant search, pull-to-refresh, Hindi typography, and offline bookmarks.
2. **Reporter Login & Internal WebView**: Authenticates reporters and launches an internal WebView to `https://www.news7india.com/wp-admin/post-new.php` to publish articles straight from mobile.
